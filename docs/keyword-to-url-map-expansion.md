# Keyword-to-URL map — 2026-10 sports expansion

One canonical URL per query cluster, for every page this release actually published.
Variants (singular/plural, "app"/"game", "free", "android", word order) are folded into the
cluster as supporting phrases, never given their own page. Evidence is Google Autocomplete
phrasing observed on 2026-10-02 (US, en) — not search volume. Earlier maps:
[keyword-to-url-map.md](./keyword-to-url-map.md), [keyword-to-url-map-250.md](./keyword-to-url-map-250.md).

Existing URLs keep the clusters they already own (for example the app pages own the exact app
names and the branded "162-0", "84-0", "40-0" and "24-0" strings; see
[keyword-research-expansion.md](./keyword-research-expansion.md#branded-clusters)).
