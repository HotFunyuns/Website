**Lao is an abugida, not an alphabet in the European sense.** Consonants carry an inherent vowel; written vowel signs modify it. That single structural fact explains most of what looks strange about the script to a first-time reader.

## The three things that make it different

### 1. Consonants come with a vowel attached

A Lao consonant on its own is not a bare sound. It carries an inherent vowel, which is pronounced unless a written vowel sign replaces it.

The consequence is that a string of consonants with no vowel signs is still pronounceable — which is not how a European alphabet behaves, and which is why counting "letters" in Lao is a slippery exercise.

### 2. Vowel signs surround the consonant

Vowel signs do not sit in a line after the consonant. They attach:

| Position | What it means for reading |
| --- | --- |
| Before the consonant | You read a sign, then jump back to the consonant it modifies |
| After the consonant | The familiar left-to-right order |
| Above the consonant | Vertically stacked with the base |
| Below the consonant | Vertically stacked below |
| Combinations | Some vowels use signs in two positions at once |

So reading Lao is not a left-to-right scan. It is a process of identifying a consonant and then gathering the signs attached to it, some of which appear before it on the page.

This is the same architecture Thai and Khmer use — [the Khmer script explained](/blog/khmer-script-explained/) covers a related system, and the general pattern transfers.

### 3. There are no spaces between words

Spaces separate phrases and sentences, not words. A line of Lao is a continuous run of characters.

That means **segmentation is part of reading**, not a skill added afterwards. A beginner who can identify every character can still not read, because they cannot tell where one word ends. The skill develops through exposure: as vocabulary grows, boundaries start appearing.

## Consonant classes and tone

Lao consonants are grouped into classes. The class of the initial consonant is one of the inputs that determines the **tone** of the syllable.

That last point is the one beginners most often get wrong, so it is worth stating directly:

**Tone is not read off a tone mark.** It is determined by the interaction of:

1. the **class** of the initial consonant,
2. the **length** of the vowel,
3. whether the syllable ends in a stop consonant, and
4. any **tone mark** present.

A tone mark modifies the result; it does not determine it alone. That is why Lao tone rules have to be learned as a small system rather than as a lookup table, and why they take longer than the character shapes.

The practical implication for study: **learn each consonant together with its class, from the first exposure.** A consonant learned without its class is a consonant you cannot use to read a syllable, and adding the class later is a second pass through the whole inventory.

## Why learn the script rather than romanisation

Romanisation of Lao is not standardised. Different sources transliterate the same word differently, and there is no way for a learner to tell which is right from the romanisation alone.

Since romanised material is easier to find, this is a genuine trap. Working from it means learning several conflicting spellings of every word, none of which is authoritative.

The script is the only stable representation. The [Unicode Lao code chart](https://www.unicode.org/charts/PDF/U0E80.pdf) is the formal reference for which characters exist and what they are called.

## A practical order for learning it

1. **Consonants in small batches, with their classes.** Ten at a time, reviewed daily, is more effective than the whole inventory once.
2. **The most common vowel signs, in each position.** Start with the ones that appear after the consonant, then add the ones that appear before — those are the most disorienting.
3. **The tone system as a concept**, before memorising specific combinations. Understanding *that* tone comes from several factors makes the rules learnable; memorising the rules first does not.
4. **Real words, immediately.** Decoding practice on actual vocabulary builds segmentation at the same time as decoding.
5. **Continuous text as early as tolerable.** Painful at first, and the only way word boundaries become visible.
